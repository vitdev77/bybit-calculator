# Bybit Risk Engine & Serverless Trading Journal

Профессиональное веб-приложение для автоматизации риск-менеджмента
и ведения облачного торгового журнала на рынке бессрочных фьючерсов
Bybit (USDT-Linear Contracts). Проект реализует реактивный расчет
параметров ордеров изолированной маржи, живой трекинг открытых
позиций и централизованную аналитику торговой эффективности.

## 🛠 Технологический стек

- **Framework:** Next.js (App Router, Serverless API Architecture)
- **Language:** TypeScript (Strict Type-Safety)
- **Styles:** Tailwind CSS (v4 Architecture)
- **Primitives:** Base UI (от MUI Development Team)
- **Icons:** Lucide React & TradingView Symbol Assets CDN
- **Database:** Neon PostgreSQL (Cloud Serverless Driver Integration)

---

## ⚡ Функциональные модули

### 📊 Риск-калькулятор изолированной маржи

- **Математическое ядро Bybit Engine:** Расчет параметров позиции
  происходит реактивно при изменении любой переменной на клиенте.
- **Спецификация Liquidation Price:** Точные формулы расчета цены
  ликвидации для LONG и SHORT позиций с жестким учетом базовой ставки
  поддерживающей маржи (MMR 0.5%) и совокупных комиссий за круг.
- **Инвариантный автоподбор плеча:** Автоматический расчет и выбор
  ближайшего шага кредитного плеча на основе допустимого риска
  депозита и ограничений конкретного торгового инструмента.
- **Лимитирование долей маржи:** Модуль PARTS_COUNT для дробления
  депозита на фиксированные фракции (1/1 .. 1/10) из интерфейса.
- **Синхронизация разрядности:** Форматирование цен и объемов строго
  по спецификациям API биржи (от 2 до 5 знаков после запятой).

### ☁️ Серверный торговый журнал и Аналитика

- **Serverless CRUD API:** Интеграция с Neon DB через драйвер
  @neondatabase/serverless для атомарной фиксации сделок.
- **Live PnL & ROI Tracking:** Автоматический расчет незафиксированной
  прибыли открытых позиций на основе потокового тикера.
- **Break-Even (BU) Calculator:** Автоматический расчет точки
  безубытка с учетом скользящего буфера проскальзывания для
  высоковолатильных активов и мем-токенов (DOGE, SHIB, PEPE, BONK).
- **Триггеры касания уровней:** Бэкенд-логика отслеживания логов
  касания ценой целевых ордеров (tp_touched / sl_touched).
- **Идемпотентность POST-запросов:** Проверка на уровне базы данных
  с возвратом кода 409 Conflict для предотвращения дубликатов.

## 📁 Архитектура и Структура проекта

Проект `bybit-calculator` включает директорию `src/app` с API-роутами (Bybit, котировки, журнал торгов) и основными страницами, компоненты интерфейса в `src/components/trading-calculator`, а также конфигурационные файлы `next.config.ts` и `tsconfig.json`.

---

## 🛠️ Переменные окружения (.env.local)

Создайте файл `.env.local` в корневой директории со следующими параметрами:

- `DATABASE_URL` — строка подключения к Neon PostgreSQL.
- `NEXT_PUBLIC_ADMIN_SECRET_KEY` / `ADMIN_SECRET_KEY` — секретные ключи для административных маршрутов.
- `BYBIT_API_URL` и `TRADINGVIEW_SCRIPT_URL` — опциональные URL для API Bybit и виджетов TradingView.

## 🚀 Инструкция по развертыванию

1. Клонируйте репозиторий и установите зависимости: `git clone https://github.com`, затем `npm install`.
2. Запустите локальный сервер разработки: `npm run dev` (доступно на `http://localhost:3000`).
3. Соберите и запустите проект для продакшена: `npm run build` и `npm run start`.
